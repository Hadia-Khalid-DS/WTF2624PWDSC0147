# Lab 01 Report

## Reflection

During this lab, I learned the fundamentals of Git version control and how to manage a project repository effectively. I practiced creating and editing HTML files, writing proper HTML structure with comments, and committing changes with meaningful messages. Working with branches taught me how to isolate experimental changes from the main codebase, which is an important skill in collaborative development. Merging branches showed me how changes from different lines of development can be combined into one. Overall, this lab gave me hands-on experience with the Git workflow that is used in real-world software projects.
